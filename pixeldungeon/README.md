# ГЛУБИНЫ — Зал стражей

Пошаговая локация на Phaser, собранная из вырезанных игровых кадров в компактных атласах `assets/floors_compact.png`, `assets/walls_compact.png`, `assets/rugs_compact.png`, `assets/props_compact.png` и `assets/actors_compact.png`.

Исходные PNG сохранены вне папки игры в `../pixeldungeon_assets_source_backup`.

## Запуск

Phaser загружается с CDN, поэтому нужен интернет. Из папки `pixeldungeon` запусти:

```powershell
npx --yes http-server -p 8000
```

Открой http://localhost:8000.

## Управление

| Действие | Клавиши | Телефон |
|---|---|---|
| Шаг | стрелки, WASD | кнопки D-pad |
| Ждать | пробел | кнопка «ЖДАТЬ» |

Враги временно отключены. Кошка у левой стены занимает клетку, шипы в центре зала непроходимы.
Подойди к кошке на соседнюю клетку, чтобы поговорить; закрыть диалог можно клавишей Esc.

## Структура

```
pixeldungeon/
├── index.html          разметка и экраны
├── style.css           оформление, адаптив под телефон
├── scene.js            Phaser-сцена, клеточное движение, бой и освещение
└── assets/
    ├── actors_compact.png         кадры игрока и врагов
    ├── floors_compact.png         каменные полы и обломки
    ├── props_compact.png          используемые предметы и декор
    ├── rugs_compact.png           ковры
    ├── walls_compact.png          прямые стены и внешние углы
    ├── cat_room_background.png    фон сцены диалога
    └── cat_idle_spritesheet.png   четыре кадра кошки для idle-анимации
```

## Что реализовано

- Квадратная тайловая карта 18×18 с внутренним полом 16×16
- Периметр собран из горизонтальных и вертикальных стеновых модулей с четырьмя внешними углами из пользовательского атласа
- Стены, границы карты, декор и ловушки блокируют движение
- Враги временно не размещаются в комнате
- Кошка у левой стены с четырёхкадровой idle-анимацией и коротким диалогом с выбором реплики
- Для диалога открывается отдельная иллюстрированная сцена: статичный фон комнаты и пиксельно масштабируемая четырёхкадровая анимация кошки из видео
- Персонажи и декор статичны; отдельно анимируется только пламя факелов
- Факелы занимают отдельные клетки пола и блокируют проход; отдельно анимируется только пламя
- Пол выложен одним видом кирпича; обломки размещены как отдельный неблокирующий декор
- Тёплый свет факелов окрашивает кладку и пол
- Пошаговые атаки, здоровье и перезапуск после поражения
