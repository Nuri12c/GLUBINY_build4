# ГЛУБИНЫ — Зал стражей

Пошаговая локация на Phaser, собранная из вырезанных игровых кадров в компактных атласах `assets/floors_compact.png`, `assets/walls_compact.png`, `assets/rugs_compact.png`, `assets/props_compact.png` и `assets/actors_compact.png`.

Исходные PNG сохранены вне папки игры в `../pixeldungeon_assets_source_backup`.

## Запуск

Phaser загружается с CDN, поэтому нужен интернет. Из папки `pixeldungeon` запусти:

```powershell
npx --yes http-server -p 8000
```

Открой http://localhost:8000.

## Управление

| Действие | Клавиши | Телефон |
|---|---|---|
| Шаг | стрелки, WASD | кнопки D-pad |
| Ждать | пробел | кнопка «ЖДАТЬ» |

Враги временно отключены. Две пустые комнаты соединены коротким коридором; в первой оставлена кошка.
Подойди к ней на соседнюю клетку, чтобы поговорить; закрыть диалог можно клавишей Esc.

## Структура

```
pixeldungeon/
├── index.html          разметка и экраны
├── style.css           оформление, адаптив под телефон
├── scene.js            Phaser-сцена, клеточное движение, бой и геометрия комнат
└── assets/
    ├── actors_compact.png         кадры врагов; старый кадр игрока из атласа больше не используется
    ├── floors_compact.png         каменные полы и обломки (обломки пока не размещены)
    ├── props_compact.png          предметы и декор (пока не размещены)
    ├── rugs_compact.png           ковры (пока не используются)
    ├── walls_compact.png          прямые стены и внешние углы
    ├── cat_room_background.png    фон сцены диалога
    ├── cat_idle_spritesheet.png   четыре кадра кошки для idle-анимации
    ├── player_down_walk.png       четыре кадра ходьбы персонажа вниз и поза покоя
    ├── player_up_walk.png         четыре кадра ходьбы персонажа вверх
    └── player_right_walk.png      четыре кадра ходьбы вправо; зеркально используется влево
```

## Что реализовано

- Карта 22×18: две пустые комнаты 8×16 соединены коридором 4×2
- Наружные и внутренние стены собраны из горизонтальных и вертикальных модулей пользовательского атласа
- Камера следует за игроком; мягкая полупрозрачная маска затемняет карту и плавно ослабляется вокруг героя
- У каждой комнаты отдельный уровень общего освещения для будущих фонарей
- Стены и границы карты блокируют движение
- Враги временно не размещаются в комнате
- Кошка у левой стены с коротким диалогом с выбором реплики
- Для диалога открывается отдельная иллюстрированная сцена: статичный фон комнаты и четырёхкадровая анимация кошки, вырезанная из видео на синем фоне
- Персонаж анимируется при шаге вниз, вверх, вправо и влево; кадр покоя вниз отражён по горизонтали, движение влево использует отражённые кадры ходьбы вправо
- В комнатах нет декора, ловушек и факелов; в первой комнате оставлена только кошка
- Пол выложен одним видом кирпича
- Пошаговые атаки, здоровье и перезапуск после поражения
